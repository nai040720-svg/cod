# 图床 (Image Hosting)

存放图片资源的目录。所有图片可通过 GitHub raw 链接直接访问。

## 访问方式

将文件放入本目录后，使用以下格式的链接引用：

```
https://raw.githubusercontent.com/nai040720-svg/cod/<分支名>/images/<文件名>
```

### Markdown 引用示例

```markdown
![描述](https://raw.githubusercontent.com/nai040720-svg/cod/main/images/文件名.png)
```
